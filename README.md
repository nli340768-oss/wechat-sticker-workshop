# 表情包共创工坊

从“我想做一个古灵精怪的角色”开始，走到独立表情、动图和微信配套素材。支持继续处理已有角色，不固定动物、画风或数量。

## 安装与分享

解压分享包，把整个 `wechat-sticker-workshop` 文件夹放入 Codex 的 `~/.codex/skills/`（自定义 CODEX_HOME 时使用其 skills 目录），重新打开会话后使用。其他支持SKILL.md的助手按各自导入方式安装。

需要具备图片生成/编辑能力的助手；脚本校验需要Python 3与Pillow。只安装这个技能不会自动获得图片或视频生成服务。

## 使用示例

- “用 $wechat-sticker-workshop 和我共创一个外表软萌、性格反骨的表情包角色。”
- “沿用这张角色图，做一套日常聊天表情，先给我看方向。”
- “把这些表情做成动图，保留文字稳定，告诉我能实现哪种动作。”
- “按照我上传的微信后台截图，补齐封面、图标、横幅和头像，并打包。”

文件检查示例：

```sh
python3 scripts/check_images.py /path/to/gifs --width 240 --height 240 --max-bytes 100000 --require-animation --require-transparent
```

这里的参数只是示例，必须替换成当前平台要求。脚本只读文件，不会修改图片，也不判断审核是否能通过。

分享包不含原作者的表情原画、私人资料或账户信息。内附案例数字是一次历史记录，不是微信永久规则。图片生成、AI内容申报及公开发行遵守实际工具和平台要求。
