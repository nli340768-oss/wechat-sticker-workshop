# 微信交付规格与实战经验

## 规格可信度

优先顺序：用户当前上传表单和完整提示截图 > 可访问的官方制作规范 > 有日期的历史记录。官网入口：https://sticker.weixin.qq.com/ 。外部转载常混用旧版数量及大小上限；无法核实时明确“待后台复核”，不拿多个转载的一致性当官方证据。

把每项要求记为：素材用途、宽、高、允许格式、最大字节、背景要求、数量要求、来源与核对日期。不确定的字段留空；“80K”按小于80000字节制作可兼容常见口径，留余量。

## 一次实际制作案例（不是通用官方标准）

2026-11-17，创作者使用一只奶团身体、长短兔耳、小乳牙、绿色领巾的角色。制作9张表情，配套图交付后，用户报告“成功提交”。没有审核通过或最终上架证据，也不能据此证明所有文件均被后台接受。

| 素材 | 当时尺寸 | 当时依据与限制 |
| --- | --- | --- |
| 动态主图 | 240×240 | 制作方采用保守工作规格；每张GIF小于100KB，透明、无限循环；9张的专辑数量是否通用未核实 |
| 专辑详情横幅 | 750×400 | 用户指定尺寸；不要据此推导当前平台大小上限 |
| 专辑封面 | 240×240 | 用户指定尺寸；输出透明PNG |
| 聊天图标 | 50×50 | 用户指定尺寸；输出透明PNG，使用简化头部 |
| 艺术家头像 | 640×640 | 用户截图明确：JPEG/PNG、每张不超过500KB；真人头像是建议而非强制 |
| 艺术家主页横幅 | 750×400 | 用户明确不超过80K；宽高被弹窗遮挡，当时沿用旧横幅尺寸，属于假设；必须重新确认 |

## 具体设计取舍

- 详情横幅：横向故事场景，角色特征一致，默认不加文字；背景是否可透明按后台确认。
- 封面：单个代表姿态，完整轮廓；不能直接缩小九宫格。
- 小图标：只保留头、耳朵和必要识别特征；50像素时不要放细小文字或复杂场景。
- 头像：头像尺寸大于聊天图标，应从高清源图重新导出，不能放大50像素文件。
- 压缩：横幅可在允许JPEG时调节质量，反复核对字节；PNG透明素材不要转JPEG后还声称透明。先保留高清母版。
- 精确尺寸：避免拉伸改变角色比例；按目标比例设计，必要时等比缩放加边距或小幅安全裁切。

## 提交前检查表

1. 张数、动静是否允许混合、当前格式上限已确认或明确标记未确认。
2. 全部文件实际尺寸和字节合规；动画帧数大于1，无限循环；每张标签对应正确文件。
3. 透明边缘没有白块、黑块、缺口，运动不裁掉耳朵或文字。
4. 独立表情与总览分开；预览GIF不能误当主图上传。
5. 用户实际要求的配套图已齐备；简介、名称、标签、作者资料、权利材料只在需要时准备。
6. 没有把“压缩完成”“上传成功”“审核通过”“公开上架”混为一谈。
